# Cut Finance Teleprompter

Teleprompter mit Aufnahme-Funktion für die Voice-Overs von **Cut Finance**.

**Öffnen:** https://cuttheuniverseyt-coder.github.io/cut-finance-teleprompter/

- Text läuft mit einstellbarem Tempo (Wörter pro Minute) über eine Leselinie
- Aufnahme direkt im Browser als unkomprimiertes WAV (48 kHz), benannt nach Szene und Take
- iPhone: in Safari öffnen, „Zum Home-Bildschirm“, Mikrofon erlauben, Aufnahmen über „Sichern / Teilen“ → „In Dateien sichern“
- Eigener Text über ✎: `## Szene`, `[Pause]`, `*Betonung*`

Keine Daten verlassen das Gerät: Aufnahmen bleiben im Browser, bis du sie speicherst.
